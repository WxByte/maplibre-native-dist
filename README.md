# MapLibre Native for iOS: SatSquatch's build

A Swift package of [WxByte/maplibre-native](https://github.com/WxByte/maplibre-native), branch
`satsquatch/globe-terrain`: MapLibre Native's globe with 3D terrain, and the additions SatSquatch's custom
layers use (the terrain's heights, draping custom layers onto it). Each version is a tag; its
`MapLibre.xcframework.zip` (device arm64, Apple-silicon simulators) is that tag's release asset.

The Android library of the same versions is at
[WxByte/maplibre-native-maven](https://github.com/WxByte/maplibre-native-maven).
